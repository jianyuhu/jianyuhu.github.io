# Jianyu Hu — Academic Website

Source for [jianyuhu.github.io](https://jianyuhu.github.io), built with GitHub Pages and Jekyll (based on Academic Pages).

## Update content

- Homepage and research topics: `_pages/about.md`
- Research page: `_pages/research.md`
- Publications: `_pages/publications.md`
- Talks: `_pages/talks.md`
- CV: `_pages/cv.md`
- Main navigation: `_data/navigation.yml`
- Author profile and site settings: `_config.yml`

## Deployment

Upload these files to the repository's publishing branch, and use the existing GitHub Pages Jekyll build. Check repository **Settings → Pages** to verify the selected publishing branch. A local preview requires Ruby, Bundler, and the gems in `Gemfile`.

This cleanup removes the original template sample posts, talks, publications, teaching entries, portfolio items, and mapping generators. Verify personal details, publication entries, and talk titles before publishing.
